Intake

One parent. One child. One shared key.

Every content or creative submission creates a Requestor parent and exactly one child request row. Both carry the same 6-character request_id.

Assignment & notifications

Work is assigned by employee ID — not account ID.

The child row’s produce column stores the assignee’s employee_id. Notification feeds are derived; read receipts are per account.
